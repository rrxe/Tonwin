# 💎 STORMY — خطوات التشغيل

1. **Supabase**: افتح SQL Editor وشغّل `sql/schema.sql` مرة وحدة.
2. **المتغيرات**: انسخ `.env.example` إلى `.env` (أو ضعها في منصة الاستضافة) واملأها.
   المهم: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `TELEGRAM_BOT_TOKEN`, `BOT_USERNAME`,
   `MINI_APP_SHORT_NAME`, `PUBLIC_URL`, `ADMIN_SECRET`, `ADMIN_IDS`.
3. **التشغيل**: `npm install && npm run build && npm start` (أو Docker: الـ Dockerfile جاهز).
4. **BotFather**: أنشئ Mini App (`/newapp`) برابط `PUBLIC_URL` واكتب اسمه المختصر في `MINI_APP_SHORT_NAME`.
   الـ webhook يُسجَّل تلقائياً عند التشغيل.
5. **لوحة الأدمن**: `PUBLIC_URL/admin` ← أدخل `ADMIN_SECRET`.
   - تبويب **الإعلانات**: ضع أرقام بلوكات Adsgram (int فقط، بدون `int-`). بلوك افتراضي + بلوك لكل مكان + بلوك للإعلان التلقائي وتوقيته.
   - تبويب **الإعدادات**: التعدين، العجلة (أوزان الاحتمالات 1–15 مع معاينة)، اليومي، الإحالات، السحب، الاشتراك الإجباري.
   - المهام، أكواد الهدايا، السحوبات، اللاعبين (حظر/تعديل رصيد)، البث الجماعي.

## الأرقام الافتراضية
- 1000 كريستال = 1$ (قابل للتعديل)
- تعدين: 2.5 كريستال كل ساعتين (إعلان عند البدء وإعلان عند الاستلام، كل واحد قابل للإيقاف)
- عجلة: 1–15، 5 لفات يومياً، إعلان لكل لفة، متوسط الربح ≈ 3.6 كريستال/لفة
- إحالة: 25 كريستال عند مشاهدة المُحال 5 إعلانات + 10% عمولة دائمة + بونص تعدين 1% لكل إحالة (حد 50%)

## السحب
- السحب متاح عبر شبكة **TON فقط**؛ خيار الطريقة مثبت في الواجهة ومفروض أيضاً من الـAPI، وليس إعداداً قابلاً للتغيير من لوحة الإدارة.
- قبل إظهار نموذج طلب السحب تظهر نافذة قناة الدفع الرسمية `@SLYMintX_payment` مع خيار فتح القناة أو المتابعة.
- لا يحتاج هذا التعديل إلى SQL migration؛ لم تتغير جداول قاعدة البيانات أو دالة طلب السحب.

## ملاحظات
- تحقق الإعلان على السيرفر بالوقت (5 ثواني) مثل SLYads، والحالة في ذاكرة السيرفر → شغّل نسخة واحدة (instance).
- إذا ما حطيت بلوك الإعلانات، المكافآت ما تشتغل (إلا إذا طفّيت `اشتراط الإعلانات` للتجربة).
